SERP Domain Index

This extension builds an exact, disk-backed hostname-label index. For example, a stored label of 0-173 matches shop.0-173.net, but not shop.example0-173.net.

Filtering

Matching is exact by label. A rule for a matches a.example.com, but does not match data.example.com. The final hostname label, such as com, is not checked.

Import

Source files are downloaded sequentially. If Firefox, Windows, or this tab closes, completed source files are preserved. Resume the build later; only the interrupted source restarts.

Sources

The full import uses 1.txt through 9.txt, a.txt through g.txt, and cdn. The cdn source intentionally has no .txt extension.
